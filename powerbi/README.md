# Power BI report

Place the saved Power BI Desktop report here as:

`Sales_Territory_Optimization.pbix`

Open the file with Power BI Desktop. The report contains an imported snapshot of the prepared data. If you refresh it on another computer, Power BI may ask you to reconnect the source CSV files.

All records are synthetic portfolio data. Capacity-target utilisation is a simulated workload-to-capacity indicator, not employee productivity. Distances are Haversine straight-line distances, not road distances or travel times.
